## AI 전달 요청 수동 확인

이 개발 세션의 AI가 `public/examples/onyu-studio.review.html`의 JSON 요청과 대상 HTML을 읽었습니다. 세 요청 모두 대상 요소가 하나씩 일치하는 것을 확인했습니다.

| 요청                                        | 반영 결과                                           |
| ------------------------------------------- | --------------------------------------------------- |
| 제목 첫 줄을 ‘나답게 머무는 공간,’으로 변경 | 첫 텍스트만 변경. 줄바꿈과 강조된 ‘온기’ 보존       |
| 주거 공간 디자인 제목 왼쪽에 집 아이콘 추가 | 기존 녹색 계열의 인라인 SVG와 제목을 같은 줄에 배치 |
| 공간 스타일링 설명 삭제                     | 설명만 삭제. 카드 번호와 제목 보존                  |

결과는 `public/examples/onyu-studio.ai-result.review.html`에 저장했습니다. 완료 메모 3개를 유지하며, 편집기에 다시 열어 변경된 화면과 완료 상태를 확인했습니다. 삭제한 요소의 완료 메모는 대상 없음으로 남습니다.

`scripts/apply-demo-review.ts`는 이 세 요청의 **수동 해석 결과를 재현하는 검증 코드**입니다. 앱의 AI API 기능이나 외부 Claude/ChatGPT 세션을 사용한 자동 검증이 아닙니다. 외부 AI가 메모를 유지하고 처리하는 정도는 사용자가 전달한 모델과 지시에 따라 달라질 수 있습니다.

## 화면 증거

2026-10-10 문서 조작 모드 추가: `npm run check` 전체 통과(단위 32개, Chrome·Edge 브라우저 42개). 메뉴 이동 후 직접 편집과 메모로 전환해도 현재 화면을 유지하고, 문구·크기 수정 후 다시 조작할 수 있음을 확인했습니다. 삭제와 실행 취소로 중첩 요소를 복구한 뒤 재조작, 첫 화면 초기화, 원본 메뉴 코드가 유지된 전달용 파일의 재열기를 검증했습니다. 조작 프레임의 부모 DOM·저장소 접근 차단, 외부 링크·폼 이동 차단, 미지의 대상 ID와 이벤트 속성을 담은 상태 메시지 필터도 검증했습니다.

내장 브라우저에서 사용자가 열어둔 와이어프레임의 전체 채팅과 1대1 채팅방으로 직접 이동하고, 직접 편집 전환 후 화면 유지까지 확인했습니다. 조작 상태는 이번 세션의 미리보기에만 적용하며 저장 파일의 초기 화면을 변경하지 않습니다. 새로 생성된 DOM·입력값·캔버스 편집 및 외부 실행 스크립트는 지원 범위 밖입니다.

2026-10-09 소스 보기 파일 열기 오류 수정: 내장 브라우저의 실제 문서에 Chromium의 `line-gutter-backdrop`, `line-wrap-control`, `line-content` 표가 저장되어 코드가 표시되는 것을 확인했습니다. 해당 소스 보기 구조를 감지하고 각 줄의 원래 HTML을 복원하도록 수정했습니다. 엔티티는 한 번만 해석하며 공백·중첩 태그·스타일·원본 스크립트와 전달용 메모를 보존합니다. 일반 문서의 HTML 코드 예제는 변환하지 않습니다.

추가 자동 검증은 복원한 페이지의 편집·메모·다운로드·재열기 및 수정 전 임시 작업의 복구를 포함합니다. 기존 소스 화면에 붙인 메모는 대상 없음으로 유지합니다. 실행 중인 완성 빌드를 갱신한 뒤 사용자의 내장 브라우저에서 임시 작업을 복구했고, 코드 대신 와이어프레임 제목·메뉴·전화기 화면이 표시되는 것을 직접 확인했습니다. 원본 파일은 변경하지 않았습니다. 실제 사용자 문서의 확인 화면은 저장소에 포함되지 않는 `.cache/source-viewer-recovered.jpg`에 보관했습니다.

- `screenshots/welcome.png`: 실행한 완성 빌드의 시작 화면.
- `screenshots/editor-notes.png`: 문구 수정·메모·전달용 저장을 마친 편집 화면.
- Playwright 실행의 `test-results/`: 시나리오별 화면 자료. 다음 실행 시 갱신될 수 있습니다.

사용 방법과 지원 범위는 프로젝트 루트의 `README.md`, AI 전달 규약은 `REVIEW_FORMAT.md`에서 확인할 수 있습니다.
