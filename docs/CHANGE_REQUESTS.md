# 변경 요청 가져오기

자유롭게 적은 수정 요청을 AI가 요소별 제안으로 정리하고, 사용자가 검토한 항목만 메모로 추가하는 기능입니다. 개인 메모, 상사의 지시, 여러 사람의 피드백, 회의록을 같은 방식으로 가져옵니다. 요청이 한 개여도 사용할 수 있습니다.

1.6.0부터 제공하는 기능입니다. 편집기와 설치된 스킬을 모두 1.6.0 이상으로 업데이트해야 합니다.

## 사용 순서

1. 로컬 연결 모드에서 HTML을 열고 상단 **변경 요청 가져오기**를 누릅니다.
2. 내용을 붙여넣거나 TXT·MD·DOCX를 선택합니다. 미리보기에서 수정할 수 있고, 제목을 생략하면 파일명 또는 ‘변경 요청’을 사용합니다.
3. **분석 요청 복사**를 누르고 기존 Claude Code·Codex 대화에 붙여넣습니다. 앱이 AI를 자동 실행하거나 별도 API에 전송하지 않습니다.
4. AI 제출 후 제안이 화면에 나타납니다. **대상 위치 보기**로 요소를 확인하고 **제안 수정**에서 문구·위치 관계를 바꾸거나, 문서에서 요소를 선택해 **선택한 요소로 재지정**합니다. Ctrl/Cmd+클릭으로 여러 대상을 지정할 수 있습니다.
5. 불명확하거나 상충하는 제안은 요청을 수정하고 대상을 선택한 다음 ‘요청을 명확히 하고 대상을 확인했습니다’를 체크합니다. 검토 저장 후 개별 승인합니다. 일괄 승인은 확인 필요 사유가 없는 선택 항목에만 적용됩니다.
6. **승인한 항목을 메모로 추가**합니다. 이때 문서의 표시 내용은 바뀌지 않습니다. 기존 실행 취소·다시 실행으로 메모 전환을 되돌릴 수 있습니다. 실행 취소 뒤 파일을 저장하면 복구한 상태도 유지됩니다.
7. 같은 패널의 **저장하고 AI 요청 복사**를 사용합니다. 이번 묶음에서 생성한 미완료 메모 ID만 전달합니다. 기존 일반 메모용 요청 복사는 전체 미완료 메모를 대상으로 하므로 범위를 제한하려면 요청 패널의 버튼을 사용하세요.
8. AI 반영 후 화면이 자동 갱신됩니다. 결과를 확인하고 **완성본 저장**으로 메모 없는 HTML을 내보냅니다.

## 원문과 검토 기록

**임시 저장**으로 분석 요청 복사 없이 제목과 요청 원문을 보관할 수 있습니다. 재실행 후 가져온 요청 목록에서 다시 선택합니다. 새 요청은 목록에서 **새 요청 가져오기**를 선택합니다. 입력 중에는 먼저 저장하거나 취소해야 다른 요청으로 이동할 수 있습니다.

원문·문단·분석 회차·검토 기록은 해당 HTML 옆 `.htmledit/`에 저장됩니다. 전달용·완성본 HTML에는 원문과 미승인 제안이 포함되지 않습니다. 묶음을 삭제하면 원문과 기록은 지워지지만 이미 생성한 메모는 남습니다.

분석 후 HTML이나 원문이 바뀌면 이전 제안을 보존하고 **재분석 필요**로 표시합니다. 다시 분석 요청을 전달하면 새 회차로 시작하며 이전 승인을 이어받지 않습니다. 이전 분석은 패널에서 열어 볼 수 있습니다. 분석 결과가 없으면 ‘수정 지시를 찾지 못했습니다’라고 표시합니다.

## 입력 제한

- TXT·MD는 UTF-8입니다. HTML·Markdown 코드는 실행하지 않고 텍스트로 취급합니다.
- 파일당 10MiB, 추출 텍스트 20만 자입니다. 초과하면 자르지 않고 오류를 표시합니다.
- DOCX는 본문 텍스트와 표 안의 문구를 추출합니다. 서식, 이미지, 머리글, 각주, 댓글, 임베디드 개체는 가져오지 않습니다. 필요한 내용은 미리보기에서 보충하세요.
- DOCX 압축 해제는 최대 50MiB·1,000항목·10초입니다. 손상·암호화된 파일은 UTF-8 TXT로 내보내 다시 가져오세요.
- 녹음·PDF·구형 DOC는 지원하지 않습니다. 원문이 AI에 전달되려면 사용자가 분석 요청을 직접 기존 대화에 붙여넣어야 합니다.

## 설치와 실행

```sh
npx --yes @woody_s/htmledit@1.6.0 install --agent all
npx --yes @woody_s/htmledit@1.6.0 open "문서.html"
```

문서가 있는 폴더에서 실행하고, 설치 후 Claude Code 또는 Codex의 새 대화에서 스킬을 사용하세요. 기존 스킬은 설치 당시의 런타임을 사용하므로 설치 명령을 다시 실행해 함께 업데이트합니다. `--agent claude` 또는 `--agent codex`로 하나만 설치할 수도 있습니다.

API와 제안 JSON 규약은 [CHANGE_REQUESTS_FORMAT.md](CHANGE_REQUESTS_FORMAT.md), 실제 AI 및 자동 테스트의 구분은 [검증 기록](CHANGE_REQUESTS_VERIFICATION.md)에 있습니다.
