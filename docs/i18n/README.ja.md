# HTMLEdit 利用ガイド

[English](../../README.md) · [한국어](README.ko.md) · [Español](README.es.md) · [日本語](README.ja.md) · [Português (Brasil)](README.pt-BR.md)

AIが生成したHTMLを画面上で編集し、要素ごとにメモを付けてClaude CodeやCodexに反映を依頼するローカルツールです。アカウントやAI APIキーは不要です。正式な対応環境はWindowsのChrome・Edgeです。

## インストールと文書を開く手順

Node.js **22.12以上**と、PC上で実行するClaude CodeまたはCodexが必要です。HTMLEditのソースリポジトリ以外のフォルダーで実行してください。

```sh
npx --yes @woody_s/htmledit@latest install --agent all
npx --yes @woody_s/htmledit@latest open "./document.html"
```

片方のみなら`--agent claude`または`--agent codex`を指定します。Claude Codeでは`/htmledit`、Codexでは`$htmledit`を呼び出すか、HTMLをHTMLEditで開くよう依頼します。スキルが表示されなければ新しいAIセッションを開いてください。元のファイルの隣に`document.review.html`を作成し、元のファイルは保持します。すでに作業ファイルがあれば、そちらを直接開きます。

## 言語

上部の**言語**メニューから韓国語・英語・スペイン語・日本語・ブラジルポルトガル語を選べます。**自動検出**はブラウザーの優先言語を順に確認し、対応言語がなければ英語を使います。地域コードはまとめて扱います。例：`es-MX → es`、`pt-PT → pt-BR`。

手動選択は接続モードでは文書やポートをまたいで保持し、ダウンロードモードでは現在のブラウザーの接続先ごとに保存します。言語を変えても、選択・入力中の文言やメモ・履歴・未保存の作業は維持します。ユーザーのHTML、`lang`属性、ファイル名、メモの内容は翻訳しません。サンプルは開いた時点の言語で表示します。

CLIは`--lang`、保存済みの手動選択、OSの言語、英語の順で決定します。`open --lang`は今回開く画面の初期言語だけを指定し、保存済み設定を変更しません。

```sh
npx --yes @woody_s/htmledit@latest open "./document.html" --lang ja
npx --yes @woody_s/htmledit@latest --help --lang ja
```

値は`ko`、`en`、`es`、`ja`、`pt-BR`です。対応する地域コードも認識します。コマンド・JSONキー・エラーコード・IDは言語によって変わりません。設定は`~/.htmledit/preferences.json`、または`HTMLEDIT_HOME`の下に保存します。設定保存に失敗しても編集内容は維持し、言語設定だけが次回に引き継がれない場合があります。

## 編集とAIへの依頼

1. 要素をクリックして文言・色・文字サイズを変更します。文言をダブルクリックすると直接入力でき、Ctrl+Enterで適用、Escでキャンセルします。IMEの変換中入力、入れ子の強調やリンクは保持します。
2. カード全体は**親要素を選択**で指定します。要素の削除、PNG・JPEG・WebP・GIF画像の差し替えができます。新しい画像はHTMLに埋め込み、レスポンシブ画像の参照も差し替えます。
3. **メモを付ける**で対象と**この要素・前・後・内側**を選び、依頼を書きます。新しい要素の追加やレイアウト変更はメモで依頼してください。番号マーカーと一覧は対応しています。
4. 入力した文言やメモを適用してから**保存してAIへの依頼をコピー**を押します。接続モードでは作業ファイルを保存して、そのパスを含む依頼をコピーします。**作業ファイルを保存**は保存のみです。ダウンロードモードではレビュー用HTMLも依頼と一緒に添付します。
5. AIとの会話に貼り付けます。スキルは`status → checkout → 候補ファイルを編集 → apply → status`を実行します。applyはリビジョンを確認し、バックアップしてから作業ファイルを更新します。未保存の変更がなければ、開いているエディターに自動で反映します。
6. 結果と完了メモを確認し、**完成版を保存**でメモや編集用IDのない`document.edited.html`を受け取ります。完成版から以前のメモは復元できません。

メモの編集・削除・完了・再開・対象変更ができます。対象がない場合や重複している場合は推測して関連付けません。削除を完了したメモは**対象なし**で残る場合があります。アプリは依頼が実現したかを自動判定しません。

未適用入力・保存エラー・競合・保存中の追加変更がある場合、コピーを中断します。保存後にクリップボードへのコピーだけ失敗した場合は、使い方の画面から依頼文をコピーできます。

## 文書の切り替え・操作・復元

**別の文書を開く**は未保存作業を保存するか確認し、Windowsのファイル選択画面を開きます。キャンセルや保存失敗では現在の文書を維持します。既存のレビュー用ファイルは上書きせず、以前のサーバーやバックアップも保持します。ファイル選択画面の標準ボタンはWindowsの表示言語に従います。

信頼できる文書では**文書を操作**でメニューやタブを移動し、目的の画面で**直接編集**または**メモを付ける**に切り替えます。**最初の画面へ**は操作状態だけをリセットし、編集やメモは保持します。元からある要素のクラス・スタイル・表示状態を扱えますが、スクリプト生成要素・フォーム値・キャンバスの編集は対象外です。画面移動とスクロールはセッション内だけの状態です。元のスクリプトは書き出しに保持します。

レビュー用HTMLには非表示のメモ・ID・英語のAI処理案内コメントが入り、通常のブラウザーには文書だけが表示されます。壊れたメモや未対応形式は保存を止めます。元のファイルを保管してから**読み取れないメモを除外**を選んでください。ブラウザーのソース表示から保存したHTMLは元の文書に復元し、通常のコード例は維持します。

接続モードの一時保存・候補・変更前と完全一致するバックアップは、文書の隣の`.htmledit/`にあります。書き込み時はリビジョンを確認します。未保存編集と外部変更が重なったら、**編集中の内容を別に保存**してから**ディスク上の内容を開き直す**を選びます。他のプログラムは書き込みロックに参加しないため、AIは直接上書きせず必ず`apply`を使います。

ダウンロードモードでは約0.6秒後に現在の接続先のIndexedDBへ最新の作業1件を一時保存します。長期保管はHTMLを保存してください。元に戻す・やり直す履歴は現在のセッションの50変更までです。一時保存の復元やAI結果の読み直しでは以前の履歴は戻りません。以前のファイルはバックアップから復元します。

## 更新・終了・アンインストール

インストールコマンドを再実行して更新し、新しいエディターセッションを開きます。実行コードは`~/.htmledit/versions/<version>`に固定され、npmキャッシュを削除しても残ります。変更済みスキルは保護されるため、エラーに表示されたフォルダーをバックアップしてから再インストールしてください。

Codexのrunnerは`~/.agents/skills/htmledit/scripts/run.mjs`、Claude Codeは`~/.claude/skills/htmledit/scripts/run.mjs`です。

```sh
node "<skill-directory>/scripts/run.mjs" status --file "./document.review.html" --json
node "<skill-directory>/scripts/run.mjs" stop --file "./document.review.html"
node "<skill-directory>/scripts/run.mjs" uninstall --agent all
```

先にサーバーを終了してください。アンインストールは管理対象のスキルだけを削除し、文書・バックアップ・設定・実行コード・動作中サーバーは保持します。独立したクラウドAI環境はPCのファイルへ直接アクセスできません。今回のバージョンではmacOS・Linuxのファイル選択と一連のブラウザー利用は正式対応外です。

## 対応範囲とデータ

CSSと画像を含む単一のUTF-8静的HTMLを使います。HTMLは最大25MB、差し替え画像は最大10MB、メモは最大5,000件・1件1〜20,000文字です。保存時にHTML表記が正規化されることがあります。外部CSS・画像・フォントのURLは保持し、関連ローカルフォルダーは収集しません。Reactアプリ、動的チャート、実行時Tailwindスクリプト依存の画面は対象外です。デスクトップ・768px・390px幅でレスポンシブ表示を確認できます。

編集・メモモードはスクリプトを無効にします。操作モードは分離したsandboxのオリジンでインラインスクリプトを実行し、エディターの保存領域や接続トークンは渡しません。外部スクリプト・fetch/XHR・フォーム・ポップアップ・上位ページ移動はブロックします。ただし文書スクリプトはプレビュー内容を読み取り、画像・スタイルのリクエストや自身のフレーム移動でデータを外部送信できます。信頼できる文書だけで使用してください。フレーム移動で操作接続が切れたら最初の画面に戻ります。

サーバーは`127.0.0.1`で選択した作業ファイルを扱います。編集権限トークンを含むURLは共有しないでください。HTMLEditはAIを呼び出さず、利用状況も収集しません。AIに文書の処理を依頼した場合は、そのサービスの料金とデータ方針が適用されます。

## 開発と参考資料

```sh
npm ci
npm run build
npm start
npm test
npm run test:e2e
npm run test:package
```

ダウンロードモードは`http://127.0.0.1:5173`を使います。Windowsの`start.cmd`でもインストール・ビルド・ブラウザー起動を行えます。ターミナルを閉じるかCtrl+Cで停止します。開発は`npm run dev`、ブラウザーテストにはChrome・Edgeが必要です。
